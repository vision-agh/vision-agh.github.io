    Event Camera and IMU Data Fusion for the Detection of Independently Moving Objects
    Author: Paweł Jerzyna
    Supervisor: Zbigniew Bubliński
    Academic year: 2026/2027 · In progress
    Collaboration: Tomasz Kryjak, Piotr Wzorek, Marcin Kowalczyk
    Abstract

    This thesis presents the design, implementation, and experimental evaluation of a modular data fusion algorithm combining event cameras (neuromorphic sensors) and an Inertial Measurement Unit (IMU) for detecting and segmenting Independently Moving Objects (IMO). The pipeline architecture ensures strict modular separation among event data acquisition/synchronization, ego-motion compensation, and spatial object clustering. A mathematical sensor fusion model incorporates gyroscopic rotation compensation and translation effects relative to scene depth. Validation is conducted on benchmark sequences from the EVIMO2 dataset under varying sensor motion dynamics. To assess real-time capabilities and computational determinism, the processing pipeline is deployed and benchmarked on an embedded multi-core ARM platform (Raspberry Pi 5 / NVIDIA Jetson), profiling event throughput, CPU utilization, and RAM usage.

    Academic year: 2026/2027 · In progress
    Collaboration: Tomasz Kryjak, Piotr Wzorek, Marcin Kowalczyk
    Abstract

    The goal of this thesis is to design, implement, and evaluate a keypoint detection and description pipeline operating directly on asynchronous event camera data streams modeled as sparse spatio-temporal point clouds (x, y, t) without intermediate image accumulation.     Author: Igor Siata
    Supervisor: Zbigniew Bubliński
    Academic year: 2026/2027 · In progress
    Collaboration: Tomasz Kryjak, Hubert Szolc
    Abstract

    This thesis focuses on the design and hardware-aware implementation of an Actor-Critic Model Predictive Control (AC-MPC) system for an autonomous Unmanned Aerial Vehicle (UAV) on embedded heterogeneous computing platforms. In this hybrid control architecture, a trained neural network (the actor) dynamically predicts the weight parameters of the MPC cost function. The AC-MPC algorithm is first reproduced, modified, and validated in simulation against standard MPC and baseline Reinforcement Learning agents. Performance, tracking accuracy, latency, and resource efficiency are directly evaluated and compared across both hardware platforms.

  4. MSc
    Efficiency Analysis of Dynamic Function eXchange Technology in an Embedded Reconfigurable Vision System
    Author: Paweł Franczak
    Supervisor: Piotr Pawlik
    Academic year: 2026/2027 · In progress
    Collaboration: Tomasz Kryjak, Marcin Kowalczyk
    Abstract

    The aim of this thesis is to design, implement, and analyze an embedded image processing system utilizing Dynamic Function eXchange (DFX) / partial dynamic reconfiguration technology to optimize FPGA resource utilization. Key vision algorithms are encapsulated into Reconfigurable Modules (RMs) that can be dynamically swapped at runtime within shared reconfigurable regions. Following a detailed review of DFX mechanisms, reconfiguration overhead, and reconfigurable architectures, both DFX-based and static (parallel module implementation) vision pipelines are constructed. A reconfiguration management system ensures seamless interaction between the static logic and active RMs. Experiments rigorously compare the static and DFX implementations across FPGA resource metrics (LUT, FF, BRAM, DSP), maximum operating frequency, throughput, processing latency, reconfiguration speed, and power consumption. The conditions under which DFX provides tangible efficiency benefits are established, with optional extensions toward automatic RM switching and deep learning/CNN accelerator integration.

    Author: Michał Filipkowski
    Supervisor: Tomasz Kryjak
    Academic year: 2025/2026 · Defended: 28 January 2026
    Collaboration: Marcin Kowalczyk
    Abstract

    This work presents a hardware architecture that implements the Contrast Maximization (CM) algorithm in Field-Programmable Gate Array (FPGA) resources for event-based vision systems. CM estimates motion parameters by maximizing the contrast of an Image of Warped Events (IWE) reconstructed from asynchronous event streams. Event-based vision sensors generate sparse data with high temporal resolution and low spatial redundancy, which makes them well suited for hardware processing. The deterministic, massively parallel structure of the FPGA is leveraged to design a deeply pipelined architecture capable of high-throughput, energy-efficient processing suitable for real-time embedded applications. This work details the hardware modules responsible for event warping, contrast computation, and iterative optimization, discusses key implementation decisions, and presents the hardware-aware optimization method used in the design. Experimental results demonstrate a substantial speed and efficiency improvement over CPU- and GPU-based implementations, with motion parameter estimation executing over 200 times faster. To the best of current knowledge, this is the first hardware architecture enabling acceleration of CM algorithm computations. Its performance is evaluated in terms of processing speed, energy efficiency, and hardware resource utilization. The proposed design is validated using an event-based object tracking application. The results confirm that the architecture provides a solid foundation for real-time motion estimation in high-speed, low-power embedded systems.

    Author: Julia Czekańska
    Supervisor: Tomasz Kryjak
    Academic year: 2025/2026 · Defended: 2 February 2026
    Collaboration: Mateusz Wąsala
    Abstract IDUB

    Event-based cameras offer high temporal resolution, low latency, and large dynamic range, making them attractive for motion estimation in robotics and autonomous navigation. This project develops, implements, and evaluates a monocular event-only visual odometry system that estimates metric 3D position and linear velocity from asynchronous event streams. Two complementary pipelines were compared: DEVO, a learning-based approach that regresses relative camera motion from spatio-temporal voxel grids using a deep neural network; and EVO, a geometric tracker-and-mapper. The thesis concludes with a discussion of limitations and directions for future work, including deployment on hardware and inertial fusion for scale robustness.

    The growing demand for low-energy computing systems is driving the development of neuromorphic models, such as Spiking Neural Networks (SNNs), and their implementation on embedded hardware platforms, including the SYNtzulu architecture. The proposed solution allows the processing of input images of arbitrary resolution while exploiting the sparsity of asynchronous event-based data.
